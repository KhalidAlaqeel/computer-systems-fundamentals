# Computer Systems Fundamentals Project

This project demonstrates basic concepts related to information science and computer engineering. It focuses on understanding how simple computer systems work through practical programming examples.

## Objectives
- Understand basic system-level concepts
- Apply programming fundamentals
- Prepare for undergraduate studies in computer engineering

## Project Overview
The project includes simple simulations that demonstrate:
- Process handling
- Memory usage
- Basic data structures

## Technologies Used
- Python 3

## Motivation
This project was created as part of my academic preparation for studying Information Science and Computer Engineering.
