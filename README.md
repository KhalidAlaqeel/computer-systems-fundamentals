# Computer Systems Fundamentals Project

This repository contains a small academic project that demonstrates fundamental concepts related to Information Science and Computer Engineering. The goal of the project is to show a basic understanding of how simple computer systems operate through clear and practical programming examples.

## Objectives
- Understand basic system-level concepts
- Apply programming fundamentals in a practical way
- Build academic readiness for undergraduate studies in computer engineering

## Project Overview
The project includes simple simulations that demonstrate:
- CPU process handling and scheduling
- Basic memory allocation and deallocation
- Fundamental data structures

Each script is intentionally kept simple to focus on core concepts rather than complexity.

## Technologies Used
- Python 3

## How to Run
Make sure Python 3 is installed on your system, then run the following commands from the project directory:

```bash```
python process_simulation.py
python memory_simulation.py
